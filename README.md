# Events API

Простой REST API сервис для управления мероприятиями, реализованный на **C# .NET 9 Web API**. Первый этап проекта демонстрирует принципы внедрения зависимостей (DI) и работы с RESTful эндпоинтами с кэшированием данных в памяти приложения.
По сути это каркас приложения с минимальным набором функциональности, который можно будет расширять дальше

## 📋 Функциональность

*   **CRUD операции** для управления событиями.
*   **Валидация данных** на уровне бизнес-логики и API.
*   **Документация API** через Swagger (OpenAPI).

## 🚀 Стек технологий

*   **.NET 9.0**
*   **ASP.NET Core Web API**
*   **Swagger / OpenAPI** (Swashbuckle)

### Доменная модель (Event)

| Поле          | Тип        | Обязательное | Описание                    |
|---------------|------------|--------------|-----------------------------|
| Id            | Guid       | Да           | Уникальный идентификатор    |
| Title         | string     | Да           | Название события            |
| Description   | string     | Нет          | Описание события            |
| StartAt       | DateTime   | Да           | Дата и время начала         |
| EndAt         | DateTime   | Да           | Дата и время окончания      |

## 🔌 Эндпоинты API

API предоставляет следующие эндпоинты (базовый путь: `/api/events`):

| Метод   | Эндпоинт      | Описание                         | Успешный ответ | Коды ошибок           |
|---------|---------------|----------------------------------|----------------|-----------------------|
| GET     | `/`           | Получить список всех событий     | 200 OK         | -                     |
| GET     | `/{id}`       | Получить событие по ID           | 200 OK         | 404 Not Found         |
| POST    | `/`           | Создать новое событие            | 201 Created    | 400 Bad Request       |
| PUT     | `/{id}`       | Полностью обновить событие       | 200 OK         | 404 Not Found, 400    |
| DELETE  | `/{id}`       | Удалить событие                  | 204 No Content | 404 Not Found         |

### 📝 Пример тела запроса (POST / PUT)

```json
{
  "title": "Важное совещание",
  "description": "Обсуждение плана на квартал",
  "startAt": "2024-05-20T10:00:00Z",
  "endAt": "2024-05-20T11:00:00Z"
}
```


## 🚀 Запуск проекта локально на Windows

### 1. Установите необходимые инструменты
- **.NET 9 SDK**: скачайте с официального сайта [https://dotnet.microsoft.com/en-us/download/dotnet/9.0](https://dotnet.microsoft.com/en-us/download/dotnet/9.0)
- **Git**: для клонирования репозитория  

Проверка установки .NET:
```bash
dotnet --version
```

### 2. Клонируйте репозиторий
```bash
git clone https://github.com/gitkosarev/practicum-events.git
git checkout -b sprint-1 origin/sprint-1
git pull
```

## 3. Восстановите зависимости
```bash
cd practicum-events
dotnet restore
```

## 4. Соберите проект
```bash
dotnet clean
dotnet build
```

## 5. Запустите проект
```bash
dotnet run --project practicum-events
```

#### По умолчанию Web API будет доступен на:
http://localhost:5278


## ИЛИ, если используете Visual Studio:
*   Откройте проект/решение
*   Выберите конфигурацию Debug и профиль IIS Express или Project
*   Нажмите F5 (с отладкой) или Ctrl+F5 (без отладки)

## 6. Проверьте работу
*   Откройте браузер:
*   http://localhost:5278/swagger
*   Если используется Swagger, вы увидите документацию API и сможете тестировать эндпоинты
